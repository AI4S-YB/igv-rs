Overview

Core Capabilities

🧬

Broad Format Coverage

FASTA, .2bit, UCSC Hubs, BAM, CRAM 3.0+, SAM, PAF, VCF, BCF 2.2, PED, GFF3/GTF/BED/bigBed, bigWig/WIG/bedGraph, BEDPE/bigInteract, SEG & GWAS.

☁️

HTTP / S3 / GS Streaming

64 KiB LRU page-cached HTTP byte-range backend with bearer token support (--auth-token).

🔬

Alignment Analytics

8 color modes (incl. MM/ML 5mC & bisulfite), 9 sort modes, 8 grouping modes, View-as-Pairs, soft-clips & reservoir depth caps.

🌐

Bidirectional igv.js Sync

Press B for live two-way TUI ↔ browser locus mirroring over SSE and POST /api/locus.

📈

Sashimi, CNV, GWAS & Circos

Live splice-junction arcs, half-block CNV matrices, Braille Manhattan peaks, and circular whole-genome SV diagrams.

⚙️

Batch, Sessions & Sockets

TOML & IGV JSON sessions, headless --batch script runner, live --port TCP commands, and 1–4 split panes.

Scripting & Caveats

Automation, Sessions & Current Caveats

# Sessions (.toml or IGV .json) + live TCP port igv-rs --session work.toml --port 60151 printf 'goto TP53\nsnapshot tp53.png\n' | nc 127.0.0.1 60151 # Headless BED / Gene snapshot batches igv-rs ref.fa -b s.bam -g genes.gtf --snapshot-genes list.txt --snapshot-out out/ --snapshot-format png
  • Split panes vs. stitched gene list: igv-rs shows 1–4 independent side-by-side panes rather than desktop IGV's single-canvas stitched exon list.
  • Browser companion scope: igv-serve binds loopback HTTP only and translates browser pan/search events back to the TUI over POST /api/locus.
  • CRAM versions: Powered by noodles-cram, requiring CRAM 3.0+.
  • Held-key debounce: Tap navigation keys rather than holding for smoother per-frame fetching on slow remote hosts.
