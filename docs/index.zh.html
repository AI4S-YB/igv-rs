概览

核心能力

🧬

全格式轨道

支持 FASTA/.2bit、UCSC Hubs、BAM/CRAM 3.0+/SAM/PAF、VCF/BCF 2.2/PED、GFF3/GTF/BED/bigBed、bigWig/WIG/bedGraph、BEDPE/bigInteract、SEG 与 GWAS。

☁️

HTTP / S3 / GS 流式读取

内置 64 KiB LRU 页缓存的异步区间请求器，支持 Bearer Token 认证（--auth-token）。

🔬

比对深度解析

8 种着色（含 5mC 修饰与亚硫酸氢盐）、9 种排序、8 种分组、View-as-Pairs、软剪切与蓄水池降采样。

🌐

igv.js 双向同步

按 B 打开内嵌网页伴侣，通过 SSE 与 POST /api/locus 实现 TUI 与浏览器双向联动。

📈

Sashimi · CNV · Circos

实时剪接弧计数、CNV 热图、盲文 GWAS 峰值，以及无头矢量/光栅全基因组环形图导出。

⚙️

批处理 · 会话 · Socket

兼容 TOML 与 IGV JSON 会话、无头 --batch 脚本、--port 实时套接字及最多 4 个分屏。

运行时 : 命令参考

命令用途
:chr1:100-500 / :TP53跳转到坐标或基因/转录本并集区域
:sort / :group / :color实时比对排序、分组与着色（支持 BAM 标签与 MM/ML 修饰）
:pairs / :softclip / :downsample控制配对视图、软剪切展示及蓄水池降采样深度
:strand / :translate / :motif开启互补链、正/反三框翻译及 IUPAC 正则基序高亮
:sashimi / :summary / :circular开关 Sashimi 弧线、修改信号汇总方式与导出全基因组环形图
:split / :unsplit新增或关闭多位点分屏（最多 4 屏）
:load / :unload / :genome动态挂载或卸载轨道并切换参考基因组
:save-session / :load-session导出 .toml 会话或导入 TOML / IGV JSON 会话
:blat <SEQ> / :graphics <proto>在线 UCSC BLAT 比对跳转与终端像素协议切换
自动化与边界

会话、批处理及已知说明

# 会话恢复与实时 TCP 控制监听 igv-rs --session work.toml --port 60151 printf 'goto TP53\nsnapshot tp53.png\n' | nc 127.0.0.1 60151
  • 多位点模式：提供 1–4 个独立并行分屏（Tab 切换），而非单画布外显子拼接模式。
  • CRAM 支持：由 noodles-cram 驱动，需使用 CRAM 3.0 及以上版本。
  • 浏览器服务：igv-serve 绑定本机回环地址，支持向 TUI 反向回传 POST /api/locus 位点变更。
